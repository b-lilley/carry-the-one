# Carry the One

A daily mental math puzzle in the spirit of Wordle.

- **Daily six:** six problems a day (add, subtract, multiply, percent, a shortcut problem, then a hard one), the same for everyone on a given date.
- **Wordle-style hints:** three tries per problem. Green = right digit in the right place, amber = digit is elsewhere in the answer, grey = not in the answer, plus a too-high / too-low arrow.
- **The shortcut:** after each problem, a step-by-step mental math trick using that problem's numbers.
- **Practice mode:** endless problems by topic at three difficulty levels.

Everything is in `index.html`: no build step and no dependencies. Stats are saved in the browser's local storage.

## Run locally

Open `index.html` in a browser.

## Deploy

Hosted with GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
